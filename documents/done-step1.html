CONTEXT HANDOFF — CoachDesk SaaS

Product

CoachDesk — multi-tenant SaaS for Indian coaching institutes (tuition centres, competitive exam prep, computer training, skill development). Manages students, batches, attendance, fees, exams, staff, parent communication.

Tech Stack (LOCKED IN)

Layer Technology
Backend PHP 8.1+ (currently running on PHP 7.4 with polyfills) / CodeIgniter 4 (HMVC), no ORM — Query Builder + native SQL
Database MySQL 8, all tables prefixed cd_, InnoDB, utf8mb4, signed INT(11) (not BIGINT UNSIGNED)
Frontend React 18 + Vite + TypeScript + Tailwind CSS + shadcn-style components
Auth Session (admin UI) · JWT + refresh tokens (React API) · password reset via hashed email tokens
Email SendInBlue via NexusSendEmail() helper (inline-CSS templates)
PDF DomPDF (tenant-branded fee receipts)
Table prefix cd_
API base /api/v1
Admin base /admin

⚠️ Important: Do NOT switch to NestJS/Prisma — the backend is complete and production-ready in CI4. This was decided deliberately (see “Decision A” below).

⚠️ KNOWN BLOCKER — Must Fix Before Frontend Works

/api/v1/dashboard returns super-admin stats or empty data for tenant users because JWT-authenticated requests don’t populate TenantContext.

The Fix

In app/Modules/Api/Filters/JwtAuthFilter.php, after successfully decoding the JWT and fetching the user, add:

\App\Modules\Api\Libraries\TenantContext::set(
    (int) $user->tenant_id,
    $payload->branch_id ?? null,
    (int) $user->id
);

Same fix also needed at the end of after() method:

\App\Modules\Api\Libraries\TenantContext::reset();

Without this, React login works but dashboard shows wrong data.
